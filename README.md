# AzureTest - .NET API

Testing the integration of Visual Studio (basic app) with GitHub Actions and Azure.

## Project Purpose
This repository serves as a testing environment to implement a full **CI/CD** pipeline using:
* **Backend:** ASP.NET Core 10.0
* **Frontend:** Custom HTML5/CSS3 templates.
* **Cloud Infrastructure:** Azure App Service
* **Automation:** GitHub Actions with OIDC Authentication.
